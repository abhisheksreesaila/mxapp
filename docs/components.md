## The rule

Before building a feature: list the components it needs, mark each ✅ / 🔨 / ❌ here, build or extend the component in `mojoui/` first (its own test, every host it can reach), then build the app from it. An app never draws something another app would need; if it does, it goes in the table above until it's extracted.
