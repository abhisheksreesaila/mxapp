What GTK 4 can do natively

  • Yes CSS transition on colour, opacity, border-radius, box-shadow, transform, min-width/min-height, padding; @keyframes; cubic-bezier(0.22,1,0.36,1) (already in the Liquid theme).
  • Yes GtkStack crossfade / slide for swapping the capsule's face; GtkRevealer and GtkPopover (autohide = click-outside closes) for the expanded panel.
  • No backdrop-filter: glass becomes solid white at 70–86% over the soft backdrop. That's why A (ink) and C (solid white) lose nothing on GTK; B loses its frost.
  • Care a widget's width comes from its content, so "width follows content" won't animate by itself. Draw the capsule in a Canvas with on_frame (we interpolate the width), or animate min-width from measured sizes.

Mac, iPhone, web

  • Mac: the real menu bar belongs to macOS. The capsule lives in the window's unified title bar, centred (NSTitlebarAccessoryViewController / a toolbar item), which is where Xcode puts its activity view, a well-known pattern.
  • iPhone: it becomes the top of the glass top bar; it can also feed a Live Activity for long streams.
  • Web: everything on this page as written (width/height transitions, backdrop blur).
  • Agent host: each state is a plain event (activity(kind, text, progress)), so the MCP host can report it too.

Rules the capsule keeps

  • One thing at a time in the face; anything older goes to Recent (expand).
  • Transient states (result, undo) fall back to idle after 4–5 s; errors stay until seen.
  • Width morphs 320 ms, the face crossfades 150 ms out / 220 ms in, one ease-out curve, no bounce.
  • Never steals focus; Undo is also Ctrl+Z, so the button is a shortcut, not the only way.
  • Reduced motion: the face swaps with a 150 ms fade, the width snaps.
