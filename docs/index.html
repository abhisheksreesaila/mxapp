Agent native

Every app is already
a set of agent tools.

The agent is a host, like GTK or the browser. Buttons, menus and fields become MCP tools on their own. No API to build, no screenshots to read.

# a real session: an agent opens a million rows and asks for a chart
→ choose-a-file  {"path": "orders_1m.csv"}
→ create-table
→ insert-chart
→ ask  {"text": "revenue by product, largest first, top 5"}
← Did ask.
  Now: chart0: 0.6 ms
  Now: inspector: Sum of revenue by product, largest first, top 5, as bars

No per-app work

A button's tag names its tool and its tooltip describes it. Every omxapp app is an MCP server from the first line.

Safe by construction

An agent can do nothing a person couldn't. A disabled button is no tool; a dialog's buttons exist only while it's open.

It hears what changed

Every call answers in words: the new texts, what opened or closed, which tools appeared.

The GPU, in the same language

Instant at a million rows.

The code that sums your data or colours a pixel is plain Mojo. With a GPU it runs there; without one, the same function runs on the CPU.
